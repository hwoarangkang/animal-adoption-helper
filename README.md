# 動物認領養小幫手

幫等家很久的孩子被看見。

很多收容所的動物進所之後沒有被宣傳，尤其老狗，幾乎沒有被認養的機會。這個工具把官方開放認養的資料整理成好找、好分享的樣子，讓你快速找到入所最久的孩子，拿到認養資訊，貼到FB社團幫牠們找家。

線上直接用，不用安裝、不用註冊：

https://hwoarangkang.github.io/animal-adoption-helper/animal-adoption-helper.html

## 資料來源

農業部農業開放資料平台的動物認領養資料，文件編號MOAOPD-API-EIR065，只顯示狀態為OPEN、也就是開放認養的動物。資料由官方每日更新，本工具不會修改官方資料，只做查詢、篩選與整理。認養前請直接聯絡收容所，確認動物還在所內、確認可認養日期。

## 怎麼用

1. 打開上面的連結，等資料載入。
2. 用篩選找你想幫忙的孩子，預設就是入所時間最久先。
3. 點一張卡片看詳細資料。
4. 按複製認養文，再按開啟原始圖下載照片，到FB貼上照片跟文字就能分享。

## 可以怎麼找

- 地區：全台灣各縣市
- 種族：狗狗、貓咪、其他動物
- 體型：小型、中型、大型
- 年紀：幼年、成年
- 毛色、性別
- 等候天數：等家超過30天、半年、1年、2年
- 關鍵字：收容編號、品種、收容所、備註、標題
- 排序：入所時間最久先，或最新先
- 每一頁顯示24筆，上方會顯示共幾筆、第幾頁

等家超過半年、超過1年的卡片會有紅色標籤，方便一眼看到最急的孩子。

## 點開卡片會看到什麼

收容編號、入所日期、入所天數、拾獲地點、公告收容所、實際所在地、品種、性別、體型、年紀、毛色、絕育情形、狂犬病疫苗情形、收容所電話、地址、備註，還有原始照片連結。

複製出來的認養文已經整理好這些重點，包含收容編號、性別、體型、年紀、毛色、絕育與疫苗情形、拾獲地點、可認養日期、收容所地點與電話，貼文時只要再補上你想說的話就好。照片請用原始圖，不要用截圖壓字版。

## 先說清楚的限制

- 官方年紀欄位只有幼年跟成年，沒有老年分級，所以沒有辦法直接篩老狗。想幫老狗，可以用等候天數篩選，再用關鍵字搜尋備註裡有寫老年的孩子。
- 官方API單次查詢最多回傳1000筆，本工具會用分頁把開放認養的資料抓完再排序，所以最久先是全部資料裡的最久先，不是只有第一頁。
- 官方資料偶爾會有缺漏，例如電話、地址或備註是空的，畫面會顯示未標示或請洽收容所，請以收容所的回覆為準。
- 如果載入失敗，畫面會有重新載入鈕，點一下就能重抓。

## 自己架一份

只要一個靜態網頁空間就能跑，不需要後端：

- 最簡單：把這個倉庫fork過去，開啟GitHub Pages，選main分支、根目錄，就能用你自己的網址分享。
- 也可以直接下載animal-adoption-helper.html，用瀏覽器打開就能用，但要能連上網路才能抓官方資料跟照片。複製功能在https環境下最穩，建議用GitHub Pages這類https空間。

本工具不會收集你的個人資料，所有篩選都在你的瀏覽器裡完成，不需要登入，也沒有帳號。
